Why this poker cannot be rigged

There is no dealer and no server. Every hand is shuffled by mental poker (SRA protocol) — the same cryptography researchers designed for trustless card games:

1

Everyone holds a key

Each player generates a secret key and publishes only the public half. Private halves never leave your browser.

2

Everyone shuffles

The deck passes seat to seat — each player encrypts and secretly shuffles it. One honest shuffler is enough to make the order unknowable.

3

Holes stay private

Hole cards decrypt through a private chain only you can complete. Nobody else can see them — not the host, not spectators.

4

Showdowns self-prove

Board and showdown cards decrypt publicly. Every client recomputes the winners independently — a false result is mathematically impossible.
